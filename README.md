# WebTV (by oli)

Simple WebTV frontend for playing HLS/iframe links. This repository contains the app files and data used locally.

Repository contents
- `index.html` — main entry (renamed from `page2.html`; original archived in `archive/`).
- `script.js` — main JavaScript for the app.
- `style2.css` — stylesheet used by the app.
- `Channels.json`, `Logos.json`, `epg-ids.json` — data files.

What I changed
- Added `README.md`
- Archived original `page2.html` and `style2.css` in `archive/`; `index.html` is the current entry point.
- Removed `proxy.js` from the repository to avoid confusion about optional local tooling.

Note about geo-restricted channels
- Einige Sender (z. B. Netplus) funktionieren möglicherweise nur, wenn Sie über eine Schweizer (CH) VPN‑Verbindung verbunden sind.
